# Wizard's Last Stand

A landscape, mobile-first pixel-art survivor / bullet-heaven game: pick a Wizard, Warrior or Ranger, dive through four biomes and five difficulties, mine rock, level up with rarity-tiered upgrades, and beat the bosses.

Single file, zero dependencies: open `index.html` or run `npm run serve`.

- `CLAUDE.md` — start here (rules, constraints, symbol map)
- `docs/GAME_DESIGN.md` — mechanics and numbers
- `docs/ARCHITECTURE.md` — how the code works
- `docs/CHANGELOG.md` — feature history and lessons
- `docs/ROADMAP.md` — open items
- `docs/TESTING.md` — Playwright tests
- `legacy/` — earlier prototypes
